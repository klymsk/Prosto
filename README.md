# Prosto.

**A modern multi-framework e-commerce marketplace platform**  
*“Prosto” = “Simple” in Ukrainian*

---

## 📋 Project Description

**Prosto** is a comprehensive **e-commerce marketplace** project that allows users to browse products, view detailed item pages, manage a shopping cart, and interact through separate buyer and seller profiles.

The project demonstrates a **multi-approach development strategy**:
- The **main application** is built with **Blazor** (Server or WebAssembly).
- Alternative implementations exist in **React**.
- A **mobile version** is developed using **.NET MAUI**.
- The project includes dedicated branches for **integration & unit tests**, as well as **performance tracing and metrics**.

This repository serves as a central hub for different technology stacks and experimental features, showcasing how the same marketplace concept can be implemented across various frameworks and platforms.

---

## 🛠 Technology Stack

### Main Technologies
- **Blazor** (.NET) — primary web application (multiple branches)
- **React** — JavaScript/TypeScript frontend (on `react` branch)
- **.NET MAUI** — cross-platform mobile application (`MAUIAPP` branch)
- **HTML5 + CSS3** — static prototype on `main` branch

### Testing & Quality
- Unit tests and integration tests (`test-branch`)
- Performance tracing, metrics collection, and quality reports (`tracing` branch)

### Other
- Responsive / adaptive design
- Modern component-based architecture
